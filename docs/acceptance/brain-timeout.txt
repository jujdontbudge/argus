## Decision and threading

The production deadline is **120,000 ms (120 seconds) per attempt**. This is
about 23x #8's measured ~5.3 s watcher-brain median and 15x #113's healthy 8.1 s
live Retro scan, while classifying #112's already-observed >2 minute tail as a
failed attempt rather than a new unbounded operating mode. It also bounds the
period in which #86's 512 MiB in-process check cannot run to less than one of
#109's 5-minute RSS floor buckets.

The value lives as `DEFAULT_BRAIN_ATTEMPT_TIMEOUT_MS` in `src/eyes/brain.ts`.
It is overridable on `CodexBrainOptions.attemptTimeoutMs`, per
`Brain.evaluate` request, and through `openRetro`'s
`brainAttemptTimeoutMs`. `Brain.evaluate` composes the deadline with a caller
signal and passes the composed signal through `SpawnRequest`. The default
runner SIGKILLs its child on abort so a timed-out `codex exec` cannot become an
orphan. Both Retro judgment paths pass the daemon signal into the brain.

## The five consequences

1. **15-minute alert restored.** The combined Retro test makes two injected
   spawns hang, advances fake retry time past 15 minutes after the first
   failure, and observes exactly one real `eye-stuck` alert on attempt 2 at
   900,001 ms. Both failure messages contain the attempt timeout.
2. **SIGTERM/shutdown restored.** The Retro-chain test aborts its controller
   after the injected spawn starts. The scan rejects with `AbortError` before
   its short watchdog; the brain-level test independently proves caller abort
   beats a 60-second attempt deadline.
3. **RSS check no longer starved.** The combined test awaits the same Retro
   scan boundary that `src/watch.ts` awaits, then reaches a counter standing in
   the exact between-tick position of the RSS check. It reaches that boundary
   after recovery and again on the eye's next scan.
4. **Machine-wide cap slot released.** The Retro shutdown test uses a one-slot
   scratch cap and reacquires it immediately after abort. The retry-survival
   test also proves the scratch slot directory is empty after timed-out
   attempts, then acquires/releases the slot again. Existing `finally` release
   semantics are now reachable because the brain wait terminates.
5. **Eye survives and continues.** Two timeouts are followed by a third attempt
   that files the original retro; the next scan returns normally. The original
   signal is not silently dropped.

## Never-drop contract

There is no give-up count and `retryForever` was not weakened. A timeout turns
one non-settling attempt into the same ordinary failure path used by nonzero
exit and schema failure: release the cap, record failure/alert state, back off,
and retry the still-pending content. The tension is latency versus retention;
the chosen resolution bounds each attempt while keeping retries infinite.

## SPEC / ADR

`SPEC.md` now states the 120-second wall-time guarantee, child termination,
slot release, and no-drop behavior. `docs/adr/0002-watcher-brain-defaults.md`
records the measured margin, the #86/#109 observability rationale, the override
locations, and the rejected no-deadline alternative.
