4. TWO PRODUCTION DEFECTS THE LIVE DRIVE FOUND
------------------------------------------------------------------------------
"Neither reachable from a fixture, and both of which would have made machine
output read as a JOHAN TAKEOVER — i.e. land in USER.md and flip
`johan_touched`."

  1. A Hermes bang-send lands verbatim headlessly.
     `derived-forms.ts` said "the `!` never lands" — true of the door it was
     measured through. In `claude -p --resume` (2.1.246) and `codex exec
     resume`, bash mode is a TUI feature and there is no TUI, so
     `!git log --oneline -3` lands as itself and matched nothing. #50's lesson
     again. Both forms are derived now; widening can only newly match text
     Hermes had already logged.

  2. codex-cli packs two envelopes into one preamble item.
     `<recommended_plugins>…</recommended_plugins><environment_context>…
     </environment_context>` in a single user-role row. The single-envelope
     filter opened on the first tag, looked for it at the end, found the other,
     returned `null`. This is #36 F3 one CLI version later. The filter now
     accepts a CHAIN of complete envelopes and nothing else;
     `"<recommended_plugins>…</recommended_plugins>\nwhy is this here?"` still
     classifies Johan.
